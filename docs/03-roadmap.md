# Roadmap — taskflow-api-dotnet

- [x] **Paso 0 — Aclaración de contexto:** Variables verificadas en `/opt/taskflow/.env.dotnet` (`APP_NAME`, `ENVIRONMENT`, `PORT=3000`, `CORS_ORIGIN=https://taskflow-api-dotnet.xprad.com`, `RATE_LIMIT_*`, `DATABASE_URL`, `DIRECT_URL`). Host público definitivo: `taskflow-api-dotnet.xprad.com`.
- [x] **Paso 1 — Estructura Base e Infraestructura:** Solución .NET 9 (`TaskFlow.Domain`, `TaskFlow.Application`, `TaskFlow.Infrastructure`, `TaskFlow.Api`) + `tests/TaskFlow.Api.Tests` (xUnit + WebApplicationFactory), CORS por `CORS_ORIGIN`, rate limit fijo por IP, security headers, `ExceptionHandlingMiddleware` con `ErrorResponse`, FluentValidation cableado, `GET /health` con sondeo real de PostgreSQL en `0.0.0.0:3000`. CI (build + tests) y deploy (SSH → `docker compose up -d --build --no-deps api-dotnet`) verificados en el VPS.
- [x] **Paso 2 — Persistencia y migraciones duales:** `TaskFlowDbContext` (Npgsql) sobre `DATABASE_URL`, `TaskFlowDbContextFactory` con `DIRECT_URL` para las herramientas EF, conversores de `status`/`priority` a los literales del contrato, migración inicial `20261123041513_InitialCreate` generada en CI (workflow `Migrations`) y aplicada en el VPS con `docker compose run --rm -T api-dotnet-migrate`.
- [x] **Paso 3 — Implementación del contrato (`docs/openapi.yaml`):** Endpoints `POST/GET/PATCH/DELETE /tasks`, `GET /tasks/{id}`, filtros (`status`, `priority`, `assignee`), paginación con `meta`, validación FluentValidation (400 con array de mensajes), errores `ErrorResponse` (404/405/500/429) y Swagger UI en `/docs`. Verificado en vivo contra el VPS (201/200/400/404/204).
- [ ] **Paso 4 — Testing:** Ampliar la suite (validadores de aplicación + endpoints con `WebApplicationFactory` y PostgreSQL real) hasta las 25 pruebas previstas.
- [x] **Paso 5a — Documentación y Docker:** `AGENTS.md`, `docs/01-architecture.md`, `Dockerfile` multi-etapa (.NET 9 Alpine: build → migrations → runtime) para VPS AWS + Traefik.
- [x] **Paso 5b — CI/CD VPS:** GitHub Actions `ci.yml` (build + test + verificación de migraciones), `migrations.yml` (genera y commitea migraciones EF Core) y `deploy.yml` (SSH → `git fetch/reset --hard` → migraciones → `docker compose up -d --build --no-deps api-dotnet` → health check). Variables en `/opt/taskflow/.env.dotnet`. Sin Render, sin registros Docker externos.
